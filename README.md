# Preventive Glucose AI — MVP v3

صوّر وجبتك واعرف وش تسوي في سكرك قبل اللقمة الأولى. تطبيق ويب (PWA) يشتغل على GitHub Pages مجاناً، والبيانات تنحفظ في جهاز المستخدم (IndexedDB).

## التسلسل
1. التسجيل خطوة بخطوة + بوابة أمان + خطة شخصية
2. اختبار المعايرة الموجّه (٥٠ جم جلوكوز، مؤقت حي، قراءات ٣٠/٦٠/٩٠/١٢٠)
3. الوجبة: صورة ← الأصناف والكميات ← طريقة الأكل وحالتك اليوم ← التوقع (A–E) ← خطة قبل/أثناء/بعد ← حفظ
4. السجل: قراءة بعد أي مدة، الفرق عن التوقع، تعديل الوجبة، والنموذج يتعلم
5. رؤاك ومكتبة الأكل (١٦٠ صنف، أغلبها من جداول هيئة الغذاء والدواء ٢٠٢٦)

## الملفات
- `index.html` الواجهة والتصميم · `app.js` المنطق · `foods.js` قاعدة الأكل
- `sw.js` + `manifest.webmanifest` تثبيت على الشاشة والعمل بدون نت
- `worker.js` خادم Cloudflare اختياري لتحليل الصور عبر Claude

## تحليل الصور
من داخل التطبيق: حسابي ← تحليل الصور ← Google Gemini، والصق مفتاح مجاني من aistudio.google.com/apikey.

## تنبيه
أداة نمط حياة، ليست جهازاً طبياً ولا تُستخدم للتشخيص.
